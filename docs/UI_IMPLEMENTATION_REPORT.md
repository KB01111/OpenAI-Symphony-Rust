ownership) and `docs/UI_ARCHITECTURE.md` (layers, contracts, streaming, routes). This report lists what
changed, how it was verified and what is still open. Every claim below is backed by a test or a
measurement in this branch; where something could not be verified here, it says so.

## 3. Components

- **Fluent UI v9** owns chrome, commands, menus, tooltips, dialogs (incl. `ConfirmDialog`), forms, tabs,
  message bars and toasts.
- **shadcn/ui** (installed with the shadcn CLI into `packages/ui/src/primitives`) owns resizable layouts,
  the command palette (cmdk), context menus, scroll areas, sheets, skeletons and table primitives
  (`DataTable` with TanStack Table + virtualization).
- **OpenAI Apps SDK UI** owns AI surfaces: `AiApprovalBanner`, `AiEventStreamCard`, `MergeReadinessCard`,
  `TaskStatusBadge`, `PhaseBadge`, `ProviderBadge`, `ApprovalStatusBadge`, `AiEmptyView`,
  `PromptComposerBox`, `LogModeSwitch`, `StreamingText` (all retained and refactored onto the generated
  contracts).

## 4. API contract changes

- All routes under `/api/v1`, axum 0.8 `{param}` syntax, `API_VERSION = 2`. Public: `health`, `runtime`.
- New/changed routes: `GET /state`, `GET /events` (SSE, named events, `ready`/`resync`, `Last-Event-ID`
  replay), `GET /events/recent`, `POST /scheduler/pause|resume`, `POST /projects/validate`,
  `GET|PATCH|DELETE /projects/{id}`, `PATCH /tasks/{id}/status`, `POST /tasks/{id}/dispatch|cancel|retry`,
  `GET /tasks/{id}/events|attempts|validations|diff`, `POST /approvals/{id}/decide`,
  `GET /prs/{id}`, `POST /prs/{id}/approve-merge`, `GET /worktrees`, `GET|PUT /workflow`,
  `POST /workflow/preview`, `GET|PUT /settings`, `GET /providers?refresh`, `GET|POST /credentials`,
  `DELETE /credentials/{key}`, `GET /diagnostics/export`.
- Errors are `{ "error": { "code", "message" } }` with 400/401/403/404/409/500 mapping.
- `CreateTaskRequest.auto_start` (alias `dispatch_immediately` accepted for older clients).
- `ProviderKind::OpenCode` serialises as `opencode` everywhere.
- `AppSettings`/`ResourcePolicy` use `#[serde(default)]` (older stored settings stay readable);
  `remote_port` default is now 47821 (distinct from the local 4780).
- State machine: manual moves never enter `running`; dispatch/retry/cancel validate transitions;
  approvals are idempotent and expire when a run ends; PR approval is idempotent, retry-safe and completes
  only a task in `human_review`; an aborted turn (and any cancelled run) ends as `cancelled`.
- Repository registration stores the checkout root (`git rev-parse --show-toplevel`).
- Diffs include untracked files, use NUL-delimited git output and are read with a byte budget.

## 5. Tauri changes

- Embedded vs attached runtime (`RuntimeMode`); discovery via `get_local_api_config` (base URL, token,
  API version, mode); `runtime.json` removed on exit.
- IPC allow-list (`build.rs` `AppManifest::commands` + `capabilities/default.json`): `get_local_api_config`,
  `open_task_workspace` (validated task worktree only, embedded mode), `pick_repository_folder`,
  `set_autostart`, `exit_application`. No shell/fs/command bridge.
- Plugins: dialog, notification, window-state, single-instance. Tray with pause/resume and quit, close to
  tray (setting), `--background` autostart, native notifications for approvals and finished attempts while
  unfocused.
- CSP (`default-src 'self'`, loopback-only `connect-src`, `object-src 'none'`, `frame-ancestors 'none'`),
  `freezePrototype`.
- Optional remote listener only with a vault `SYMPHONY_REMOTE_TOKEN` (≥16 chars), never on the local port.

## 6. Design decisions

- **Rust is the only authority**; the UI never changes state locally except optimistic status moves that
  roll back on rejection.
- **Generated contracts** instead of hand-written TS types; CI fails when they drift.
- **Event stream drives targeted invalidation** (100 ms batches) instead of blanket polling; polling is a
  fallback while the stream is down and is throttled while hidden.
- **One owner per component category** (§3) and one token source (`tokens.css`) feeding Tailwind, shadcn,
  Fluent and Apps SDK. Global CSS is imported first to lock the cascade-layer order (found via screenshots:
  Apps SDK buttons were otherwise reset by Tailwind preflight). Density changes body text, not the root
  font size, so rem- and px-based libraries agree.
- **Data router** so views can guard unsaved edits.
- **Same-frame double submit** is blocked synchronously (ConfirmDialog, workflow save, onboarding) —
  tests found real double POSTs before these guards.

## 7. Security changes

See `SECURITY.md` §4–5. Summary: bearer auth on all non-public routes; CORS allowlist; no tokens in URLs;
credential allowlist; server-chosen workflow path; recursive config redaction; bounded diff reads;
atomic OS-level runtime lock; owner-only discovery file on Unix; same-origin-only dev discovery; IPC
allow-list; CSP; never auto-merges (merge readiness is advisory and approval is an explicit action).
`validate_workspace_path`, `workspace_key_for_identifier` and `SECRET_ENV_VARS_TO_STRIP` are unchanged.

## 10. Known limitations

- **Native Windows behaviour is not verified by these tests.** Browser E2E cannot exercise the tray,
  window state, notifications, autostart, folder picker or Explorer integration. The new
  `desktop-native.yml` workflow builds the Tauri app on `windows-latest`; a successful build there proves
  compilation and bundling only, not runtime behaviour, which still needs a manual check on Windows 11.
- **iOS**: the mobile companion is a web app validated by typecheck/build/unit tests (and the existing macOS
  CI job); no native iOS packaging was attempted or claimed.
- **Windows ACL on `runtime.json`**: relies on the per-user data directory; no explicit owner-only DACL yet.
- **Hardware telemetry** never probes the GPU (by design, to avoid waking a discrete GPU); GPU metrics are
  therefore not shown.
- **Provider pause**: no provider supports mid-turn pause, so the action is not offered.
- **Bundle size**: Fluent and Apps SDK chunks exceed 500 kB raw; further splitting (e.g. lazy Markdown /
  code highlighting inside Apps SDK) is possible.
- **Simulated agent only in CI**: real Codex/Claude Code/OpenCode runs are never dispatched in CI (no paid
  models); their drivers are covered by unit tests and detection only.
- **Raw workflow source** is returned unredacted to authenticated clients so it can be edited (see
  SECURITY.md §4); credentials belong in `$VAR` references.
